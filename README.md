# 🌿 MoGo — Интерактивный и отзывчивый лендинг креативного агентства

Яркий, сочный и полностью адаптивный одностраничный сайт-презентация для креативной дизайн-студии. Проект реализован по классическому многослойному дизайн-макету и демонстрирует навыки работы со сложной блочной структурой, графикой и интерактивными интерфейсами.

🚀 **Живое демо проекта:** [Проверить в действии](https://shaomdev.github.io/mogo/)

---

## ✨ Ключевые особенности и технические решения

- **Сложная многокомпонентная структура:** Верстка включает в себя Hero-экран, секцию услуг, детальную статистику, команду, портфолио работ, отзывы и карту.
- **Гибкая Flexbox-раскладка:** Все контентные сетки, карточки команды и элементы галереи выстроены на чистом CSS Flexbox, что обеспечивает идеальное выравнивание.
- **Интерактивные UI-элементы:**
  - Реализован плавный скролл к секциям.
  - Кастомные текстовые аккордеоны (раскрывающийся список услуг) на чистом CSS/JS.
- **Эффекты наложения и ховеры:** Карточки команды и галерея имеют сложные ховер-эффекты с плавным появлением полупрозрачного цветного градиента и иконок соцсетей при наведении.
- **Тотальная адаптивность:** Сайт ювелирно адаптирован под все типы экранов (десктопы, планшеты, смартфоны). Сетка меню и текстовые блоки аккуратно перестраиваются для удобного чтения на мобильных устройствах.
- **Чистый код по стандартам:** Разметка полностью семантична, стили структурированы для удобной поддержки.

---

## 🛠 Технологический стек

- **HTML5** — валидная семантическая разметка страницы.
- **CSS3** — кастомные переменные, сложные CSS-анимации, переходы (`transition`), медиа-запросы (`@media`).
- **БЭМ-архитектура** — модульная структура классов для масштабируемости.
- **JavaScript** — базовые сценарии для оживления интерактивных элементов интерфейса (плавный скролл, аккордеоны).

## 💻 Локальный запуск (Local Setup)

Если вы хотите запустить проект на своем компьютере:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/shaomdev/mogo.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd mogo
   ```
3. Откройте файл `index.html` в любом браузере.
